Squircle – Quintic Superellipse

border-radius: 28% approximiert die quintic Superellipse (n=5). Weicher als ein Rechteck, strukturierter als ein Kreis. Apple nutzt diese Form seit iOS 7 für App-Icons – heute UI-Standard. Kein border-radius: 50% für quadratische UI-Elemente.

07

Voice & Copy Guidelines

Wie die Marke kommuniziert. Ton, Stil, Verbote. Diese Sektion wird pro Projekt mit echten Beispielen befüllt.

Richtig
  • Kurze, klare Aussagen mit konkretem Nutzen
  • Aktive Formulierungen: „Wir liefern" statt „Es wird geliefert"
  • Konsistente Anrede – entweder immer „Sie" oder immer „du"
  • Konkrete Zahlen: „in 48 Stunden", „7 Jahre Erfahrung"
  • Headlines die eine Erwartung erfüllen oder aufbrechen
Falsch
  • Leere Floskeln: „Qualität und Kompetenz"
  • Anglizismen im deutschen Fließtext ohne Notwendigkeit
  • Wiederholung des gleichen Satzbaus in einer Section
  • Übertreibungen ohne Belege: „Der beste Service"
  • Emojis im Fließtext oder in Headlines
Klar vor clever

Der Nutzer versteht in 3 Sekunden worum es geht. Wortspiele nur wenn sie nicht auf Kosten der Klarheit gehen.

Konkret statt abstrakt

„Website in 7 Tagen live" schlägt „schnelle Umsetzung". Immer mit Zahlen, Zeitangaben oder Beispielen arbeiten.

Konsistente Anrede

Projektbeginn: Anrede festlegen. Dann konsequent durch alle Texte. Niemals mischen.

Motion & Animation

Alle 8 Pflicht-Animationen als live Demo. Klick auf „Abspielen" triggert die Animation. Alle Demos funktionieren offline ohne externe Libraries. prefers-reduced-motion wird überall respektiert.

01 · Hover Lift
translateY(-6px) 200ms ease-spring :hover

→ Hover auf den Block. Anwendung: Cards, Buttons, Link-Elemente.

02 · Fade Slide Up
opacity 0→1 translateY 20px→0 600ms ease-spring
03 · Line Reveal (Hero Text)
translateY 20px→0 Stagger 150ms 600ms
04 · Skeleton Shimmer
linear-gradient sweep 1500ms infinite perceived performance

→ Läuft automatisch. Anwendung: Ladezustände aller async Bereiche.

05 · Button Active Scale
scale(0.95) 100ms instant :active

→ Klick und halten. Sofortiges Klick-Feedback ohne Verzögerung.

06 · Color Transition
Hover
background transition 300ms ease-in-out

→ Hover für Farbwechsel. Standard für alle Hover-Farbübergänge.

07 · Nav Blur on Scroll
Navigation · Scrolled: nein
backdrop-filter: blur(16px) 300ms onScroll
08 · Parallax Scroll
Hero Background
translateY scrollY * 0.35 will-change: transform passive listener

→ Seite scrollen für Parallax-Effekt im oberen Bereich.

Token Wert Ease Anwendung
--duration-instant 100ms ease Button :active, sofortiges Klick-Feedback
--duration-fast 200ms ease Hover States – Farbe, Border, Schatten
--duration-base 300ms ease-in-out Standard-Transitions, Nav Blur, Color
--duration-slow 600ms ease-spring Scroll-Reveal, Hero-Text, Fade Slide Up
--duration-crawl 1000ms ease Skeleton Shimmer, Ambient Loops
--ease-spring cubic-bezier(0.22, 1, 0.36, 1) — Überschiessend, lebendig – Cards, Hover Lift
--ease-out cubic-bezier(0.0, 0, 0.2, 1) — Natürliche Verzögerung – Modals, Drawers
--ease-in-out cubic-bezier(0.4, 0, 0.2, 1) — Symmetrisch – Farb-Übergänge, Nav
prefers-reduced-motion – Pflicht bei jeder Animation
/* Bewegung aktiv (Standard) */ .element { transition: transform var(--duration-fast) var(--ease-spring); } .element:hover { transform: translateY(-4px); } /* Bewegung reduziert – nur Farbe, keine Bewegung */ @media (prefers-reduced-motion: reduce) { .element { transition: background var(--duration-fast); } .element:hover { transform: none; } } /* In JavaScript prüfen */ const noMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
09

Assets & Meta-Specs

Technische Spezifikationen für Fonts, Favicon, OG-Image und Deployment. Der DSGVO-konforme Weg zur lokalen Font-Einbettung ist hier vollständig dokumentiert.

DSGVO · Fonts lokal einbetten (Pflicht)

Google Fonts CDN übermittelt die IP des Besuchers an Google → DSGVO-Verstoß. Für deployete Websites: @font-face mit lokalem Dateipfad. Für offline verschickte HTML-Dateien: Font als base64 Data URI direkt im <style>-Block.

❌ Verboten

<!-- IP geht an Google --> <link href="https://fonts.googleapis.com/ css2?family=Inter" rel="stylesheet">

✓ Richtig – Server

@font-face { font-family: 'Inter'; font-weight: 400; font-display: swap; src: url('/fonts/inter-400.woff2') format('woff2'); }

✓ Richtig – Offline Single-File HTML (base64)

@font-face { font-family: 'Inter'; font-weight: 400; font-display: swap; src: url('data:font/woff2;base64,d09GMgABAAAAA...') format('woff2'); } /* Schritt-für-Schritt: 1. WOFF2 herunterladen: google-webfonts-helper.herokuapp.com 2. macOS/Linux: base64 -i inter-400.woff2 | tr -d '\n' 3. Windows PS: [Convert]::ToBase64String([IO.File]::ReadAllBytes("inter-400.woff2")) 4. String oben eintragen – pro Weight eine @font-face Regel Nur verwendete Weights einbetten (400, 500, 700) */
Favicon
  • Format SVG (vektorbasiert, skaliert perfekt)
  • Viewport Quadratisch – z.B. viewBox="0 0 100 100"
  • Pfad /images/logo/favicon.svg
  • HTML-Tag <link rel="icon" type="image/svg+xml" href="...">
  • Fallback favicon.ico für ältere Browser
OG Image (Social Sharing)
  • Format PNG oder JPG (kein SVG – WhatsApp ignoriert es)
  • Größe 1200 × 630px (Verhältnis 1.91:1)
  • Pfad /images/og-image.png
  • Tags og:image, twitter:image, JSON-LD image
  • Mindestgröße 600 × 315px (kleinste Empfehlung)
Bilder
  • Format WebP für alle Inhaltsbilder
  • Desktop max. 200 KB
  • Mobile max. 100 KB
  • Einbindung <picture> + srcset immer
  • Lazy Loading loading="lazy" (außer LCP-Element)
  • Alt-Text Pflicht auf jedem Bild
Icons
  • Einbindung Immer Inline SVG – nie CDN, nie Icon-Font
  • Lizenz Heroicons (MIT), Lucide (ISC), Phosphor (MIT)
  • Größe 16px / 20px / 24px – je nach Kontext
  • Stroke-Width 1.5 oder 2 – projektweite Konsistenz
  • Dekorativ aria-hidden="true" setzen
  • Funktional aria-label Pflicht
Deployment
  • Vor jedem Deploy ./check.sh ausführen (DSGVO, Assets, A11y, Rechtliches)
  • Git Explizit stagen (nie git add -A) → commit → push → tag
  • Kein Deploy ohne Impressum, Datenschutz, DSGVO-konforme Fonts
  • Checkliste GUIDES/KERN/DESIGN_SYSTEM.md → Go-Live Checkliste
