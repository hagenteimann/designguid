# Impeccable – Alle Befehle

Skill von pbakaus/impeccable. UI-Polish, Audit und Verbesserung in 23 Befehlen.

**Installation:** `npx skills@latest add pbakaus/impeccable --global`

---

## Befehle nach Kategorie

### Analyse & Audit
| Befehl | Was es tut |
|---|---|
| `/impeccable audit` | Vollständiger Design-Review – listet alle Probleme auf |
| `/impeccable critique` | Kritische Bewertung ohne Fixes |
| `/impeccable compare` | Zwei Designs oder Zustände vergleichen |

### Visuell verbessern
| Befehl | Was es tut |
|---|---|
| `/impeccable polish` | Allgemeines Verfeinern – Spacing, Farbe, Typografie |
| `/impeccable distill` | Auf das Wesentliche reduzieren – Noise entfernen |
| `/impeccable clarify` | Visuelle Hierarchie schärfen |
| `/impeccable balance` | Komposition ausbalancieren |
| `/impeccable elevate` | Von gut zu exzellent |

### Typografie
| Befehl | Was es tut |
|---|---|
| `/impeccable typeset` | Typografie-System verbessern |
| `/impeccable kern` | Buchstabenabstand optimieren |
| `/impeccable flow` | Text-Flow und Lesbarkeit verbessern |

### Farbe
| Befehl | Was es tut |
|---|---|
| `/impeccable colorize` | Farb-System entwickeln oder verbessern |
| `/impeccable harmonize` | Farbpalette harmonisieren |
| `/impeccable contrast` | Kontrast-Verhältnisse prüfen und fixen |

### Struktur & Layout
| Befehl | Was es tut |
|---|---|
| `/impeccable structure` | Layout-Architektur überarbeiten |
| `/impeccable grid` | Grid-System aufbauen oder reparieren |
| `/impeccable space` | Spacing-System vereinheitlichen |

### Interaktion
| Befehl | Was es tut |
|---|---|
| `/impeccable animate` | Micro-Interactions und Transitions |
| `/impeccable respond` | Responsive-Verhalten verbessern |
| `/impeccable harden` | Konsistenz und Robustheit sichern |

### Spezial
| Befehl | Was es tut |
|---|---|
| `/impeccable adapt` | An anderen Stil/Kontext anpassen |
| `/impeccable extract` | Design-Tokens oder Muster extrahieren |
| `/impeccable document` | Design-Entscheidungen dokumentieren |

---

## Wann welchen Befehl

```
Design sieht generisch aus      → /impeccable audit  → /impeccable elevate
Farben passen nicht zusammen    → /impeccable colorize + /impeccable harmonize
Zu viele Elemente, unruhig      → /impeccable distill
Schriftbild unprofessionell     → /impeccable typeset + /impeccable kern
Abstände inkonsistent           → /impeccable space
Mobile-Darstellung kaputt       → /impeccable respond
Vor Abgabe/Deploy               → /impeccable audit  (immer!)
```

---

## Typischer Workflow

```
1. /impeccable audit          – Probleme identifizieren
2. /impeccable polish         – Schnell-Verbesserung
3. /impeccable colorize       – Farb-System verfeinern
4. /impeccable typeset        – Typografie fixem
5. /impeccable audit          – Ergebnis prüfen
```
