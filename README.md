## Repo-Struktur

```
designguid/
│
├── GUIDES/
│   ├── KERN/          ← Immer relevant (Tokens, Design System, Regeln)
│   ├── WEBSITE/       ← Website-Projekte (Funnel, SEO, Deploy, Legal...)
│   └── EXTENDED/      ← Nur bei Bedarf (Analytics, API, Browser...)
│
├── CHECKLISTS/        ← 1-Seiten Quick-Referenzen
├── TEMPLATES/         ← Plan-Vorlagen (Landing Page, Portfolio...)
├── SKILLS/            ← Skill-Dokumentation
├── Beispiele/         ← Fertige Design System HTML (READ ONLY)
│                            Arche_designsystem.html = Blueprint / Referenz
├── Projekt/           ← Arbeitsordner für neue Projekte
│
├── guides-index.json  ← Aufgabe → Datei Router
├── CLAUDE.md          ← Regeln für Claude Code
├── AGENTS.md          ← Regeln für alle anderen Agenten
├── check.sh           ← Pre-deploy Checks
└── ralph.sh           ← Ralph Loop starten
```
