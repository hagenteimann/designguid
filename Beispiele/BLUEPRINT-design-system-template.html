03 Foundations

Grid System & Unit Base

Decision: 4pt unit grid as token base, 8pt as layout minimum. This is the standard for modern design systems (Linear, Vercel, Radix).

  • --space-1: 4px — Micro-details only (icon padding, tight typography, borders)
  • --space-2: 8px — Component internal spacing
  • --space-3: 12px — Micro margins
  • --space-4: 16px — Standard component padding
  • --space-6: 24px — Section spacing
  • --space-8: 32px — Large component spacing
  • --space-12: 48px — Page section gaps
  • --space-16: 64px — Major layout breaks

Square & Circle Rule (Superellipsen)

What: UI elements should be based on perfect squares and circles. Text/content sits inside, maintaining clear proportion ratios.

Best Practices for Loading States

  • Always show loading indication: Prevent user confusion about whether the app is working
  • Use skeleton screens: More perceived speed than spinners (mimics actual layout)
  • Shimmer animation: Smooth gradient sweep from left to right for better UX
  • Progressive content: Load above-the-fold first, then below
  • Timeout handling: Show error state if loading takes > 30 seconds
  • Never jump layouts: Keep skeleton placeholder same size as real content

13 Responsive Design

Breakpoints & Behavior

Mobile (XS) 0–640px
Mobile Landscape 641–1024px
Desktop (MD) 1025–1440px
Wide (LG) 1441px+

Mobile-First Approach

Principle: Design and code for mobile first with single-column layouts, then progressively enhance for larger screens using min-width media queries.

Progressive Enhancement Flow:

Mobile (Base) Single column, stacked layout, large touch targets
Tablet Enhancement @media (min-width: 641px) — 2 columns
Desktop Enhancement @media (min-width: 1025px) — 3+ columns
Wide Enhancement @media (min-width: 1441px) — Full width, max-width constraint

CSS Example (min-width approach):

/* Base: Mobile */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet: 2 columns */
@media (min-width: 641px) {
  .card-grid {
    grid-template-columns: 1fr 1fr;
  }
}

/* Desktop: 3 columns */
@media (min-width: 1025px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
  • Touch targets: Minimum 44×44px on all mobile devices
  • Navigation: Hamburger menu on mobile, horizontal nav on 768px+
  • Typography: Scaled viewport units (clamp) for responsive font sizes
  • Images: Use <picture> element for art direction across breakpoints

Fluid Spacing

Use fluid (calc-based) spacing for smooth scaling between breakpoints:

padding: calc(1rem + 2vw);

Full-Width Layout Strategy

Define 3 layout patterns for managing content width across the viewport.

Contained (Default) max-width: 1200px; margin: 0 auto
Full-Width Section width: 100%; padding-horizontal
Bleed Section Full-width background + contained text
Use Case Heroes, CTAs, testimonials, banners

CSS Patterns:

/* Contained Layout (default) */
.layout-contained {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 var(--space-6);
}

/* Full-Width Section with contained inner content */
.section-full-width {
  width: 100%;
  background: var(--clr-primary-50);
  padding: var(--space-12) var(--space-6);
}

.section-full-width .inner {
  max-width: 1200px;
  margin: 0 auto;
}

/* Bleed: Edge-to-edge with content constraint */
.section-bleed {
  width: 100vw;
  position: relative;
  left: 50%;
  right: 50%;
  margin-left: -50vw;
  margin-right: -50vw;
  padding: var(--space-12) var(--space-6);
}

Best Practices:

  • Use bleed sparingly: Only for hero sections, CTAs, testimonials
  • Maintain breathing room: Always add horizontal padding on mobile
  • Avoid overflow: Never use 100vw on the body (causes horizontal scrollbar)
  • Consistent max-width: Keep all contained content at 1200px maximum

15 Dark Mode & Black Mode

Two distinct dark themes with different purposes: Dark Mode for reduced eye strain, Black Mode for OLED screens and maximum contrast.

Three Theme Modes

Light Mode

Default theme. High contrast on white backgrounds. Best for bright environments.

Dark Mode

Dark navy/charcoal backgrounds. Reduced blue light emission. Comfortable for long sessions.

Black Mode

True black (#0a0a0a) backgrounds. Optimal for OLED screens — pixels are physically off, saving battery.

CSS Token System

Use CSS custom properties to swap all colors at once. Never hardcode colors in components.

/* Light Mode (Default) */
:root {
  --clr-bg-main: #ffffff;
  --clr-bg-secondary: #f8f9fa;
  --clr-text-main: #212529;
  --clr-text-secondary: #495057;
  --clr-border: #e9ecef;
}

/* Dark Mode */
[data-theme="dark"] {
  --clr-bg-main: #1a1a2e;
  --clr-bg-secondary: #16213e;
  --clr-text-main: #e2e8f0;
  --clr-text-secondary: #a0aec0;
  --clr-border: #2d2d44;
}

/* Black Mode (OLED) */
[data-theme="black"] {
  --clr-bg-main: #0a0a0a;
  --clr-bg-secondary: #121212;
  --clr-text-main: #f0f0f0;
  --clr-text-secondary: #b0b0b0;
  --clr-border: #1a1a1a;
}

Theme Toggle Implementation

/* JavaScript: Toggle between themes */
function setTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem('preferred-theme', theme);
}

/* On load: Respect user preference */
const saved = localStorage.getItem('preferred-theme');
const system = window.matchMedia('(prefers-color-scheme: dark)').matches;

if (saved) {
  setTheme(saved);
} else if (system) {
  setTheme('dark');
}

/* CSS: Auto Dark Mode via media query */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --clr-bg-main: #1a1a2e;
    --clr-text-main: #e2e8f0;
  }
}

Contrast Rules for Dark Mode

Body text on dark bg Minimum 7:1 (WCAG AAA)
Primary color on dark bg Use lighter shades (200–400 range)
Shadows on dark Use rgba(0,0,0,0.5) — not light shadows
Images on dark Reduce brightness 80% if needed
Black Mode text #f0f0f0 not pure #ffffff (avoids glare)
OLED Benefit True black pixels = physically off = 0% power

Implementation Best Practices

  • Never hardcode colors in components — always use CSS tokens
  • Test all states: Hover, focus, disabled in all three modes
  • Avoid pure white (#ffffff) in dark mode — use off-white (#f0f0f0) to reduce glare
  • Elevation with lighter backgrounds — in dark mode, higher elevation = slightly lighter bg
  • Respect prefers-color-scheme — auto-detect OS preference as default
  • Persist user choice — save to localStorage, apply before paint to avoid flash
  • Image treatment — consider filter: brightness(0.8) for photos in dark mode
